# Changelog

All notable changes to Pay On Arc are documented here.

## v1.0.0

- Added wallet signed-message authentication.
- Added merchant dashboard and settings.
- Added merchant profiles and checkout branding.
- Added Arc Testnet ERC-20 USDC payment links.
- Added one-time payment link locking.
- Added server-side USDC transfer verification.
- Added transaction records, status checks, and analytics.
- Added API key creation, revocation, and usage tracking.
- Added signed webhooks and delivery logs.
- Added durable background worker for webhook delivery and transaction checks.
- Added AI Copilot for merchant payment insights.
- Added secret-path admin panel with wallet allowlist.
- Added audit logs, security headers, rate limiting, and health endpoint.
- Added production deployment documentation.
